# Serverless Image Resizer (Project 9)

This project demonstrates a serverless architecture using **AWS Lambda** and **Amazon S3** to automatically resize images when they are uploaded.

## Architecture Overview

1.  **Source S3 Bucket**: Users upload their original high-resolution images here.
2.  **S3 Event Notification**: Triggered upon image upload (`s3:ObjectCreated:*`).
3.  **AWS Lambda**: A Python-based serverless function that intercepts the upload event, downloads the image, resizes it using the `Pillow` library, and uploads the smaller version to the destination bucket.
4.  **Destination S3 Bucket**: Stores the resized images.

## Technologies Used
- AWS Lambda (Python 3.9)
- Amazon S3
- Boto3 (AWS SDK for Python)
- IAM (Role and Policies for Lambda execution)

## Deployment Instructions

### Prerequisites
1.  Python 3.7+ installed.
2.  AWS CLI configured with appropriate credentials (`aws configure`).
3.  `boto3` library installed (`pip install boto3`).

### Automated Deployment

Run the included deployment script to provision the infrastructure automatically:

```bash
python deploy_infrastructure.py
```

**What the script does:**
- Creates a source S3 bucket and a destination S3 bucket.
- Creates an IAM Role with permissions to read from the source and write to the destination bucket.
- Packages the `lambda_function.py` into a ZIP file.
- Creates the Lambda function, automatically attaching an open-source AWS Lambda Layer (KLayers) containing the `Pillow` dependency.
- Configures an S3 event notification on the source bucket to trigger the Lambda function.

### Testing the Resizer

1.  Find the names of the source and destination buckets generated by the script in the terminal output.
2.  Upload an image (JPEG, PNG, etc.) to the **source bucket**:
    ```bash
    aws s3 cp my-large-image.jpg s3://<YOUR_SOURCE_BUCKET_NAME>/
    ```
3.  Check the **destination bucket** to see the resized image!
    ```bash
    aws s3 ls s3://<YOUR_DESTINATION_BUCKET_NAME>/
    aws s3 cp s3://<YOUR_DESTINATION_BUCKET_NAME>/my-large-image.jpg ./resized-image.jpg
    ```

## Notes on Dependencies (Pillow)
Because AWS Lambda runs on Amazon Linux, Python packages with native C extensions (like `Pillow`) must be compiled for that architecture. 
This project elegantly bypasses the need for manual packaging via Docker or AWS SAM by utilizing a public Lambda Layer provided by [KLayers](https://github.com/keithrozario/Klayers). The deployment script dynamically links this layer to the Lambda function.
